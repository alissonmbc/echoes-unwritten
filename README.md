# Echoes Unwritten

An explorable Three.js scene: a wanderer and a small black cat walk a cobblestone cliff road at sunset toward the castle city of Lumina.

**Play it:** https://alissonmbc.github.io/echoes-unwritten/

## Run locally

The page loads Three.js through an import map, so it needs a local server:

```bash
python -m http.server 8765
```

Then open http://localhost:8765/.

## URL options

| Parameter | Effect |
| --- | --- |
| `u=0.5` | Start at a position along the road (0 to 1). Turns auto-walk off. |
| `yaw=0.3`, `pitch=0.02` | Set the starting camera angle. |
| `noglb` | Use only the procedural models. |
| `shot` | Skip the opening fade. |

## Rebuild the models

The archway, lamp, rocks and city are generated by the Blender scripts in `blender/`:

```bash
blender --background --factory-startup --python blender/build_all.py
```

`python blender/check_glb.py` lists what is in each GLB. The character models in `assets/` were made separately and aren't produced by these scripts.
